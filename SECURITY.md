# Seguridad

Si encuentras una vulnerabilidad en NEXUM OSINT, repórtala de forma privada desde la
pestaña **Security > Report a vulnerability** del repositorio, sin abrir un issue público.
Responderé en un plazo razonable y publicaré la corrección con el crédito correspondiente.

Las API keys y cookies se guardan solo en tu equipo (`~/.config/nexum-osint/config.toml`,
permisos 600) y nunca se envían a servicios distintos del que corresponde a cada una.
